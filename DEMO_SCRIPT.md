# ProofPilot — 3-minute demo

## 0:00–0:20 — Problem
"Many AI research demos ask once and answer once. ProofPilot makes the research process visible and gives the user a traceable evidence ledger."

## 0:20–0:40 — Goal
Use: "Compare open-source agent frameworks for a student project, including trade-offs and official documentation." Show the search budget.

## 0:40–1:30 — Agent loop
Run the agent. Point out planning, live search, page inspection, coverage review, possible adaptive follow-up, and logged tool errors. Explain that it is bounded and observable.

## 1:30–2:15 — Evidence
Open the evidence ledger and click a source. Compare source links with extracted text. Open the agent trace to show observations.

## 2:15–2:40 — Deliverable
Open the brief and download Markdown and JSON. Mention possible uses: literature review, technology selection, opportunity research.

## 2:40–3:00 — Close
"ProofPilot plans, calls tools, observes results, adapts within a budget, and leaves an auditable trace. It surfaces evidence and uncertainty rather than pretending generated text is automatically true."
